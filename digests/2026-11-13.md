# Research radar, 2026-11-13

## Read today

**[CapLite: Prompt-Injection Defense for Small Language Model Agents without Model-Written Security Artifacts](https://arxiv.org/abs/2611.17115)**  
MCP and tool security · score 8/10 · arxiv  
The paper argues that small language model agents should not be trusted to write their own security artifacts for prompt-injection defenses. It proposes CapLite, a tool-schema-based enforcement method that restricts writes to user-stated targets and reports no successful attacks across 13,935 AgentDojo episodes.  
Why it matters to you: It is directly about defending agent tools against prompt injection and over-privileged write actions, which fits the MCP/tool-security thread.  
Read it asking: How well does CapLite's user-stated-write guarantee generalize beyond AgentDojo-style tasks to real MCP servers with richer, multi-step, or stateful tool interactions?

**[Contain, Conform, Compare (Extended Version): A Red-Teamed Evaluation Kit for Small Coding Agents and the Full Record of Its Experiments](https://arxiv.org/abs/2611.16485)**  
Agent privilege escalation · score 7/10 · arxiv  
A red-teamed local evaluation kit for small coding agents that runs jobs in fresh no-network containers, checks that local requests match the hosted scorer, and releases full run-level experiment data. It reports containment/escape testing and statistical comparisons of prompt and agent changes on coding tasks.  
Why it matters to you: It connects to agent-escalation by focusing on sandboxing, escape tests, and safe execution of agent-written code.  
Read it asking: How strong are the 200 scripted escape tests against real privilege-escalation paths in coding agents, and what does the no-network container miss?

**[Intent-Aware Protection for AI Agents](https://arxiv.org/abs/2611.16122)**  
Agent privilege escalation · score 7/10 · arxiv  
The paper proposes an intent-aware security framework for AI agents that uses an agent-specific intent profile to detect deviations from the agent's intended role, purpose, or operational boundaries. It introduces a benchmark and several protections, including pre-execution detection, post-execution detection, input alignment, and system-prompt hardening.  
Why it matters to you: It connects to agent-escalation by treating intended agent purpose as a runtime policy reference for catching behavior that may stay within permissions but still exceeds the agent's deployed role.  
Read it asking: How well does the intent profile generalize to new tools, permissions, or tasks, and can it distinguish benign task drift from malicious privilege escalation?
