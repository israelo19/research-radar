**[Threat Landscape of Vibe Coding and the Road to Secure Autonomy](https://arxiv.org/abs/2611.21822)**  
Agent privilege escalation · score 8/10 · arxiv  
A survey-style paper that maps security threats in vibe coding and AI coding agents, proposing autonomy levels, trust boundaries, a 21-threat taxonomy, and research challenges for secure agent operation.  
Why it matters to you: It directly addresses coding-agent privilege escalation, tool/cloud access, and enforceable limits on agent authority.  
Read it asking: Which threats in the taxonomy are most likely to enable real privilege escalation in current coding agents, and which proposed defenses actually constrain agent authority at runtime?

**[GapLeak: When Privacy-Preserving LLM-based Web Agents Become a Privacy Risk](https://arxiv.org/abs/2611.22223)**  
Agent privilege escalation · score 7/10 · arxiv  
The paper shows that LLM-based web agents can be induced to submit unauthorized sensitive information when a legitimate form creates an information gap, even without prompt injection. It evaluates this across web-agent frameworks and LLMs and proposes submission-time verification as a runtime defense.  
Why it matters to you: It is directly about agents exceeding least-privilege constraints and a runtime policy defense, which fits agent privilege escalation.  
Read it asking: Does submission-time verification generalize beyond web forms to broader agent actions, tool calls, or computer-use tasks?
