## Read today

**[The Detour Is the Danger: Preserving Security During LLM Agent Recovery](https://arxiv.org/abs/2611.33605)**  
MCP and tool security · score 9/10 · arxiv  
The paper studies how LLM agents using MCP/Skill-style tools can silently drop security protections when they recover from execution failures. It proposes ARGUS, an obligation-preserving recovery framework that validates and enforces security requirements during replanning.  
Why it matters to you: It directly addresses security failures in MCP/Skill agent workflows, especially how tool-using agents can bypass original protections during autonomous recovery.  
Read it asking: Which recovery detours most often drop security obligations, and can they be detected from execution traces alone?

**[MINE: A Training-Free Defense against Indirect Prompt Injection via Mutual Information and Embedding Variance](https://arxiv.org/abs/2611.34188)**  
MCP and tool security · score 8/10 · arxiv  
The paper proposes MINE, a training-free defense against indirect prompt injection in RAG and agent tool-call settings by maximizing relevance rather than detecting attacks. It also introduces a long-context injection benchmark and evaluates against adaptive attackers.  
Why it matters to you: It directly addresses prompt injection through retrieved or tool-provided content, which is central to MCP and agent tool security.  
Read it asking: How well does MINE hold up when malicious tool output is highly relevant to the user's task and mimics legitimate tool responses?
