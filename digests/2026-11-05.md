# Research radar, 2026-11-05

## Read today

**[SecureGARD: Dynamic Ontology-Guided Governance for Secure Tool-Using LLM Agents](https://arxiv.org/abs/2611.06682)**  
MCP and tool security · score 9/10 · arxiv  
The paper proposes an ontology-guided governance framework for tool-using LLM agents that makes deterministic ready, waiting, and forbidden decisions about tool calls. It reports a 0% attack success rate on AgentDojo, ASB, and AgentDyn under indirect prompt-injection settings while improving task utility under attack.  
Why it matters to you: It directly addresses prompt injection into tool-using agents and how to constrain tool execution without indiscriminately blocking useful actions.  
Read it asking: How robust is the ontology-based defense against adaptive attacks, tool-description poisoning, or tools and workflows not covered by the verified training executions?

**[Signed, Sealed, Leaked: Trust Beyond Signature for MCP Toolchains](https://arxiv.org/abs/2611.06585)**  
MCP and tool security · score 9/10 · arxiv  
The paper shows that a signed MCP tool can still leak confidential data by embedding it in requests to an allowed destination, and that a state-of-the-art runtime defense can miss this. It proposes germline execution, which runs each tool invocation in isolated copies with only authorized data, and reports strong empirical and theoretical results.  
Why it matters to you: It directly addresses malicious behavior in authenticated MCP tools and runtime defenses for agent toolchains.  
Read it asking: How well does germline execution handle tools that need persistent state, cross-invocation coordination, or legitimate side effects?

**[Securing Web Agents with the Compile-Then-Execute Paradigm](https://arxiv.org/abs/2611.06039)**  
Agent privilege escalation · score 8/10 · arxiv  
Baya is a compile-then-execute web agent that plans a Python program against a trusted website API before observing live webpage content, aiming to prevent prompt-injection-driven control-flow hijacking. It reports strong utility on WebArena Verified and 0% attack success rate on the WASP web-agent security benchmark.  
Why it matters to you: It is a design-level defense for computer-use/web agents against prompt injection causing unintended actions or access, with benchmark evidence.  
Read it asking: How much does Baya depend on the trusted website API and compile-time action space, and what happens when tasks require dynamic operations that cannot be anticipated before execution?
