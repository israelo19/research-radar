## Read today

**[Beyond Instruction Override: Benchmarking Indirect Prompt Injection with Task-Tampering Attacks](https://arxiv.org/abs/2611.07640)**  
MCP and tool security · score 9/10 · arxiv  
A new benchmark for indirect prompt injection in tool-using agents that tests attacks which tamper with an ongoing task's decision rather than replacing the task. It evaluates how well detection/removal and tool-policy defenses handle attacks targeting objectives, rules, actions, observations, and state.  
Why it matters to you: It directly extends prompt-injection-through-tool-output research by showing that task-tampering attacks can evade defenses that only catch instruction-override attacks.  
Read it asking: Which of these task-tampering targets are most likely to appear in real MCP or tool-server outputs, and which defenses would actually catch them?
