## Read today

**[Tether: Verified Stateful Policy Engine for System-Level Monitoring of Agents](https://arxiv.org/abs/2611.25599)**  
Agent privilege escalation · score 9/10 · arxiv  
Tether is a runtime policy engine that executes agent actions in ephemeral sandboxes, infers abstract semantics from system calls, and enforces stateful Lean 4 policies for IFC, access control, and network restrictions. It reports blocking 100% of in-scope attacks on coding-agent benchmarks with under 5% benign false positives.  
Why it matters to you: It is a direct defense for coding agents executing arbitrary commands, addressing sandboxing, runtime policy, and preventing unauthorized network, file, or privilege side effects.  
Read it asking: Which attack classes are out of scope, and how does the policy language handle dynamic code generation, interpreters, or multi-agent tool calls?

**[Replication of Agentic Security Events: Audit and Investigation (ROGUE-AI)](https://arxiv.org/abs/2611.26553)**  
MCP and tool security · score 7/10 · arxiv  
A framework that replays 108 reported LLM-agent incidents offline with and without the blamed cause, finding that many harms come from ordinary task hazards rather than prompt injection. It also shows that hazard-naming warnings after tool output reduce harm more than neutral notes.  
Why it matters to you: It connects to mcp-security by testing prompt-injection-related tool-output defenses and showing non-injected tool hazards can be more dangerous.  
Read it asking: Which incident categories are most likely to be missed by current prompt-injection defenses, and how generalizable are the hazard-naming warnings?
